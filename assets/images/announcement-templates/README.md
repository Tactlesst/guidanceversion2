# Announcement backgrounds

Four original portrait background PNGs created with the built-in image-generation tool. The announcement title and message stay editable in the website.

Choose a background in Create Announcement, or open View > Visibility & template settings for an existing notice. Classic blue retains the original layout without a background image. Saving an existing notice's template does not resend notifications.

- blue-gold.png — general and important notices
- teal-guidance.png — guidance and support
- purple-academic.png — academic updates
- coral-events.png — events and activities

Open index.html to browse the designs. Exact generation prompts are saved in prompts.json.
